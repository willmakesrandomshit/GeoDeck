# Community standards

GeodeSync aims to be a constructive place to report problems and improve the project. Be respectful, assume good faith, and focus criticism on the work rather than the person.

Unacceptable behavior includes harassment, threats, discrimination, doxxing, and repeated disruptive conduct. Maintainers may edit or remove contributions and restrict participation when needed to keep project spaces usable.

Report a conduct concern privately to the repository owner using the contact information on the owner's public GitHub profile. Do not include sensitive personal information in a public issue.
