=====================================================
          GeodeSync for macOS — launch guide
=====================================================

DOWNLOAD STATUS
No macOS app is currently published on the official Releases page. Release
packages are withheld until they can be Developer ID signed and notarized.
Do not use an older unsigned preview or bypass Gatekeeper warnings.

COMPATIBILITY
- Apple silicon build: macOS 11 Big Sur or newer.
- Intel build: macOS 10.15 Catalina or newer.
- Geometry Dash installed through Steam.

The GitHub workflow can build and test macOS bundles for Apple silicon and Intel,
but a CI build is not a published or notarized download. Target OS versions are
build settings, not a claim that every Mac or Steam installation is tested.

FEATURES
The app's feature availability depends on the current GeodeSync version and
the user's Steam/Geometry Dash installation. Review each action in the app
before applying changes.
