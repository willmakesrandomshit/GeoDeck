# GeodeSync roadmap

This is a set of maintenance priorities, not a promise of dates or unreleased functionality. Priorities may change as bugs and platform support are reviewed.

## Current priorities

- Keep the supported Windows and Linux release instructions aligned with actual published assets.
- Keep save backup, game switching, archive validation, and update recovery covered by regression tests.
- Improve contributor onboarding and make supported platform limitations easy to find.
- Publish macOS packages only after the signing and notarization process is available and verified.
- Review bundled artwork and third-party notices before adding a repository-wide open-source licence.

## Later, if there is a demonstrated need

- Improve platform-specific smoke testing on real Steam and Steam Deck installations.
- Document manual recovery steps for interrupted game-file operations.
- Review dependency update and release provenance practices.

Items move forward when there is a clear user problem, a safe implementation, and a way to verify the result.
